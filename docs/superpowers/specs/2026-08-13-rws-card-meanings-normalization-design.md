# RWS 카드 의미 정규화 설계

## 목표

`frontend/data/cards.ko.json`의 카드 의미를 현대 Rider–Waite–Smith(RWS) 해석의 공통 핵심으로 통일한다. 현재 정상인 카드명, 번호, 슈트, 이미지, 데이터 구조와 모든 `ox` 값은 유지한다.

## 범위

- 명확히 현대 RWS와 다른 13장의 역방향 의미와 키워드를 교정한다.
- Waite 원전식 특수 의미가 섞인 11장의 표현을 현대 RWS 핵심 의미로 정리한다.
- 이미 현대 RWS에 맞는 분야별 상세 설명은 보존한다.
- 요약과 충돌하는 상세 설명만 함께 교정한다.
- `detailUp.ox`와 `detailRev.ox`는 어떤 카드에서도 변경하지 않는다.

## 해석 기준

현대 RWS 자료들에서 반복되는 공통 키워드를 우선한다. 출처마다 허용되는 역방향의 양극 해석은 오류로 보지 않는다. 다음 경우만 수정 대상으로 삼는다.

1. 현대 RWS의 핵심 방향과 반대인 경우
2. 다른 카드의 대표 의미가 섞인 경우
3. Waite 원전의 오래된 특수 의미만 남아 현대 RWS 맥락이 사라진 경우
4. `meaningRevKo`, `keywordsRevKo`, `detailRev`가 서로 모순되는 경우

## 수정 전략

### 명확 오류

여사제, 여황제, 악마, 완드 3, 완드 4, 완드 킹, 컵 8, 소드 3, 소드 4, 소드 6, 소드 7, 펜타클 에이스, 펜타클 5의 역방향 요약과 키워드를 현대 RWS로 교체한다.

소드 3 역방향은 상세 설명도 회복·용서·고통 해소 방향으로 맞춘다. 소드 6 역방향의 고백 관련 상세는 전환 지연·과거의 짐·변화 저항으로 교체한다.

### 혼합 표현

황제, 교황, 운명의 수레바퀴, 별, 완드 5·6·8, 컵 2, 소드 에이스·2의 역방향에서 원전식 특수 표현을 제거하고 현대 RWS 공통 핵심을 보강한다. 완드 킹 정방향의 `뜻밖의 좋은 소식`은 비전과 리더십에 맞는 표현으로 교체한다.

### 유지 대상

- `id`, `nameEn`, `nameKo`, `arcana`, `suit`, `number`, `image`
- 모든 `detailUp.ox`, `detailRev.ox`
- 현대 RWS 범위에 있는 기존 문구
- 역방향에서 인정되는 양극 해석

## 검증

변경 전 `ox` 값을 별도로 기록하고 변경 후 카드별로 완전히 동일한지 비교한다. 다음 조건도 자동 검증한다.

- JSON 파싱 성공
- 카드 수 78장
- ID 78개 모두 고유
- 메이저 22장, 마이너 56장
- 각 마이너 슈트 14장
- 모든 카드에 정·역방향 의미, 키워드, 상세, `ox` 존재
- 감사에서 식별한 비RWS 문구 제거
- 프로젝트의 기존 카드 검증 및 테스트 통과

## 비범위

- `ox` 판정 체계 변경
- 카드 UI 및 타입 구조 변경
- 카드 이미지 변경
- 카드 데이터 78장 전면 재작성
- 타로 해석 외 기능 수정
